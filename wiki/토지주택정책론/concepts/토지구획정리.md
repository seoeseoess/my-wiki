# 토지구획정리

**한 줄 정의**: 불규칙하게 분산된 농업용 토지나 미개발 토지를 토지이용계획에 따라 엮어 구획을 정리하고, 필요한 최소한의 기반시설을 설치하여 토지이용효율을 높여 이용가치가 높은 토지(주로 도시용 토지)로 전환하는 사업. 개발 후 토지를 재분배(환지)하여 원소유자에게 돌려주는 방식이다. 직접 개입 수단의 하나이다. (토지주택정책론/Week5 p.18)

- 토지 일부는 매각하여 공공과 사업비로 활용(체비지)하고, 나머지를 돌려주는 구조 (토지주택정책론/Week5 p.18, 슬라이드 주석)

## 사업 절차 (토지주택정책론/Week5 p.19)
- 3단계: 계획, 개발, 환지
- 정부나 토지소유자의 소청(원문 표기)으로 이루어지며, 시행자는 주로 정부나 공공기관
- 사업시행자는 토지구획정리 기본계획을 작성하여 관계부처 승인을 받아야 함
- 기본계획이 승인되면, 사업자는 구체적인 토지구획정리사업계획(환지계획 포함)을 작성

## 환지계획 작성 기준 (토지주택정책론/Week5 p.20)
- 도시개발법 제28조(환지계획의 작성) ②: 환지계획은 종전의 토지와 환지의 위치·지목·면적·토질·수리(水利)·이용상황·환경, 그 밖의 사항을 종합적으로 고려하여 합리적으로 정하여야 한다.

| 학설 | 내용 |
|---|---|
| 면적주의 | 종전 토지 및 환지의 면적(위치, 지목, 면적)을 고려하여 환지계획을 수립 |
| 평가주의 | 종전 토지의 토질, 수리, 이용상황, 환경을 고려하여 환지계획을 수립 |
| 절충주의 | 종전 토지에 대하여 면적주의를 원칙으로 하고 평가주의를 고려하여 환지계획을 수립 |

- 우리나라는 면적주의를 원칙으로 하고 평가주의를 고려하는 **절충주의**를 채택 (토지주택정책론/Week5 p.20)

## 적응환지와 보류지·체비지·감보율 (토지주택정책론/Week5 p.21)
- 적응환지 원칙: 환지계획은 종전의 토지와 환지의 위치, 지목, 면적, 토질, 수리, 이용상황, 환경 등 사항을 종합적으로 고려하여 합리적으로 정함
- 적응환지가 적용되지 않는 경우는 **보류지**(reserved land)
  - 시행자는 도시개발사업에 필요한 비용을 충당하기 위해 사업구역 내 일부 토지를 보류지로 정할 수 있음
  - 이 보류지의 일부를 **체비지**로 정하여, 도시개발사업에 필요한 경비를 충당할 수 있음
  - 보류지 중 체비지로 지정되지 않은 토지는 일반적으로 공공시설을 위한 용지로 사용됨
  - 보류지 지정으로 인해, 돌려주는 토지는 예전의 것보다 작은 것이 일반적임
  - 예전의 토지면적에 비해 작아진 비율을 **토지부담률(감보율)**이라고 부르며, 실제 사업에는 20~40%의 감보율이 적용됨

## 환지 계산 예 (토지주택정책론/Week5 p.22)
예) 감보율이 50%이고, 시행자가 정한 과소토지의 기준이 200㎡인 경우. (슬라이드 이미지에서 직접 확인함)

| | A | B | C | D | E (공공시설) |
|---|---|---|---|---|---|
| 본래 토지면적 | 400 | 500 | 300 | 100 | 300 |
| 감보율 적용면적 | 200 | 250 | 150 | 50 | 150 |
| 환지처분면적 | 200 | 200 (-50) | 200 (+50) | (건물+공유지분) / X | 700 |
| 환지방법 | 적응환지 (청산금 X) | 감환지처분 (청산금 지급) | 증환지처분 (청산금 징수) | 입체환지처분 (소유자 동의) / 환지부지정 (임차인 동의) | 환지기준부 적용 (위치, 면적 X) |
| 성격 | | 손실보상금 | 부당이득 반환금 | | |

- Week6 p.8에도 같은 표가 실려 있다(표 내용 동일, Week6 p.8에는 손글씨 메모가 추가되어 있음). 원본 이미지: [[Week6_p08.png]] (토지주택정책론/Week6 p.8)
- D열은 표에서 두 칸으로 나뉘어 있다. 왼쪽 칸은 환지처분면적 "(건물+공유지분)"에 입체환지처분(소유자 동의), 오른쪽 칸은 환지처분면적 "X"에 환지부지정(임차인 동의)이다. "본래 토지면적 100"과 "감보율 적용면적 50"은 두 칸에 걸쳐 있다.

**확인 필요 (표 자체만으로는 해석하지 않음)**
- 각 환지방법(적응환지, 감환지, 증환지, 입체환지, 환지부지정)이 과소토지 기준 200㎡ 및 감보율 적용면적과 어떤 기준으로 연결되는지는 슬라이드에 설명이 없다 → 강의 설명 확인 필요. (토지주택정책론/Week5 p.22)
- E열의 환지처분면적 700이 어떻게 산출되는지 표에 근거가 없다 → 확인 필요. (토지주택정책론/Week5 p.22)
- "손실보상금", "부당이득 반환금"이 각각 B, C열에 배치되어 있다는 것만 확인했다. 법적 성격에 대한 추가 설명은 원자료에 없음. (토지주택정책론/Week5 p.22)

## 장점 / 한계
| 장점 (토지주택정책론/Week5 p.23) | 한계 및 구조적 문제 (토지주택정책론/Week5 p.24) |
|---|---|
| 공공이 직접 토지를 매입하지 않고 개발 가능 → 재정 부담 적음 | 구획정리사업지역과 그 주변 지역 지나친 지가 상승 초래 경향 |
| 토지 소유권을 유지하면서 개발 가능 → 사유재산권 침해 적음 | 체비지 매각 의존 → 사업성이 우선되는 개발로 흐를 가능성 있음 |
| 기반시설 확보 + 토지가치 상승 동시에 달성 가능 | 토지이용이 계획보다 시장논리에 의해 결정되는 경향 있음 |
| 체비지를 통해 사업비 충당 → 공공재정 의존도 낮음 | 토지소유자 간 형평성 문제 발생(환지 위치·면적 차이) |
| 도시 확장 초기 단계에서 효율적인 개발 수단으로 기능함 | 사업 절차 복잡 및 이해관계 조정 어려움 → 사업 장기화 |
| | 개별 필지 단위에서는 효율적이지만, 도시 전체 차원에서는 비효율 발생 가능 → 공간구조의 불균형 및 무질서한 개발 초래 |
