# 토지 보유 유형

**한 줄 정의**: 토지의 보유 양태는 다양하며, 6가지로 구분한다(사적·공공의 자유보유/임대보유, 비공식 사실보유, 공동체 보유). (토지주택정책론/Week5 p.4)

## 6가지 유형 (토지주택정책론/Week5 p.4)
| # | 유형 | 내용 | 예시·비고 |
|---|---|---|---|
| ① | 사적 자유 보유 (Private Freehold) | 개인이 완전한 소유권 보유 | 자본주의 시장에서 가장 보편적 |
| ② | 사적 임대 보유 (Private Leasehold) | 개인 또는 기업이 개인 토지소유자로부터 약정 기간·조건 하에 대여 | |
| ③ | 공공 자유 보유 (Public Freehold) | 정부·공공기관이 완전한 소유권 보유 | e.g. 국·공유지 |
| ④ | 공공 임대 보유 (Public Leasehold) | 개인 또는 기업이 정부 소유 토지를 약정 기간·조건 하에 임대 | |
| ⑤ | 비공식 사실 보유 (Nonformal de facto tenure) | 토지 원소유자의 공식적 허락 없이 토지를 점유한 형태 | e.g. 국공유지 불법 무단 점유. 미개발 후진국에서 다수 나타남 |
| ⑥ | 공동체 보유 (Communal ownership) | 지역공동체 또는 집단이 공동으로 토지를 보유·이용 | |

## 사적 자유 보유제도의 문제점 (토지주택정책론/Week5 p.6)
- 전략적 버티기(Hold-out)
- 독과점 문제
- 부의 편중
- 사례(슬라이드 제시): 조선일보(2025. 2. 4.) "도로 한 가운데 섬처럼 고립된 외딴집… 중 '알박기'의 최후" 기사
- 원자료에는 사적 자유 보유의 "장점" 항목이 별도로 정리되어 있지 않음(①에 "자본주의 시장에서 가장 보편적"이라는 설명만 있음).

## 공공 보유의 한계 (토지주택정책론/Week5 p.7)
원문은 이를 "④ 관료제 문제 (공공 보유의 한계)"로 제시한다.

| 구분 | 내용 |
|---|---|
| 이론 | 공공 자유·임대 보유는 정부가 수요에 맞춰 빠른 용도 결정 가능 |
| 현실 | 토지 수요 변화에 둔감한 관료제 → 용도 결정·변경 지연 |
| 결과 | 국·공유지가 효율적으로 이용되는 사례 매우 드묾 |
| 사례 | LH 보유 토지 중 장기 미활용지 누적, 그린벨트 해제 수십 년 표류 |
| 핵심 | 공공 보유의 비효율 |

### 이론상 장점 vs 현실적 한계 — 공공 보유의 역설 (토지주택정책론/Week5 p.7)
| 이론상 장점 | 현실적 한계 |
|---|---|
| 즉각적 용도 결정 가능 | 관료제 → 수요 변화 둔감 |
| 공공목적 우선 배분 | 정치적 이해관계 개입 |
| 투기 억제 | 장기 미활용지 누적 |

- 최선: 잘 짜인 토지이용계획 + 공·사 혼합 보유 체계 (토지주택정책론/Week5 p.7)
